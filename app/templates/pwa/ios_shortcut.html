iOS Shortcut Setup

Submit your Wordle score directly from the Wordle app using an iOS Shortcut.

Your API Key

Copy this key — you'll need it when setting up the Shortcut.

Setup Instructions
1
Open the Shortcuts app on your iPhone and tap + to create a new Shortcut.
2
Add a "Receive Input from Share Sheet" action. Set "Share Sheet Input" to Text.
3
Add an "Ask for Input" action. Set the prompt to "Add a comment (optional)". Save the result as Comment.
4
Add a "Get Contents of URL" action with these settings:
URL: {{ request.host_url }}api/submit
Method: POST
Body: JSON
Fields:
auth_key = {{ g.user['auth_key'] }}
score = Shortcut Input
comment = Comment (variable)
5
Add an "Open URLs" action. Set the URL to:
{{ request.host_url }}
This opens the app after submitting.
6
Name the Shortcut something like "Submit Wordle" and add it to your home screen.
Using the Shortcut
  1. Finish your Wordle puzzle
  2. Tap Share in the Wordle app
  3. Scroll down and tap Submit Wordle (your shortcut)
  4. Optionally enter a comment
  5. Done! Your score is submitted automatically

Enable Notifications

Push notifications require the app to be installed and notifications to be allowed in your device settings.

iOS (iPhone / iPad)
  1. Add this app to your Home Screen (Share → Add to Home Screen)
  2. Open the app from your Home Screen (not Safari)
  3. When prompted, tap Allow for notifications
  4. If you missed the prompt: go to Settings → Notifications → Safari and enable
Android
  1. Install the app (browser menu → Install App or Add to Home Screen)
  2. When prompted, tap Allow
  3. If blocked: Settings → Apps → Wordle Tournament → Notifications → Allow
Desktop Chrome / Edge
  1. Click the lock icon (or settings icon) in the address bar
  2. Find Notifications and set it to Allow
  3. Reload the page, then click Enable notifications in your profile
  4. If no permission prompt appeared, notifications may have been previously blocked — step 1–2 above resets that

Also check Windows settings: Start → Settings → System → Notifications → make sure Edge is allowed to send notifications.
